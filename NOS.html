COMMAND CENTER

Speak. Type. Command.

ULTRON is built around a simple command interface. These are examples of the kind of interactions the system supports.

help
Display available ULTRON commands.
mic on
Activate the microphone interface.
mic off
Disable microphone listening.
open vscode
Launch Visual Studio Code.
memory
Access the local memory system.
